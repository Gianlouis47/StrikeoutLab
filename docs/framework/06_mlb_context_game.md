# 06 — MLB Context Game

> Ver `00_marco_transversal.md` para el marco obligatorio compartido.

## Alcance
Captura factores externos a pitcher y lineup que cambian oportunidad,
entorno o calidad de enfrentamiento.

## Variables
Verificar umpire y zona de strike, parque, temperatura, viento, humedad,
techo, travel spot, descanso, bullpen disponible y fatiga, pitch count y
probabilidad de salida corta o larga. Considerar si el manager tiene
incentivos para retirar pronto, si existe riesgo de blowout y si el
bullpen reduce la expectativa de que el abridor complete innings.

## Uso
Convertir el contexto en ajustes explícitos, pequeños y trazables. No usar
clima o narrativa de viaje para anular señales fuertes sin evidencia. Si
una variable crítica no está confirmada, reducir confianza o pasar a No
Bet.
