# 08 — Star Sport Master

> Ver `00_marco_transversal.md` para el marco obligatorio compartido.

## Propósito
Mantener la base específica del establecimiento y actualizarla con cada
captura, ticket o regla nueva.

## Registro obligatorio
Documentar mercados, límites, cantidad máxima de selecciones, payout,
reglas de push y void, restricciones, correlaciones, códigos, cambios de
mercado, cambios de línea, liquidación y comportamiento observado del
book. Separar reglas confirmadas de hipótesis.

## Construcción
No usar el máximo permitido como objetivo. Primero seleccionar patas con
edge real, luego revisar correlaciones, payout y riesgo de liquidación.
Antes de enviar un ticket verificar código, jugador, mercado, línea, cuota
y fecha.

## Formato
Código; Pitcher; Rival; Línea; Over/Under; Cuota; Confianza; Motivo;
Estado —fuerte / media / débil / no tocar—.
