# 07 — MLB Sharp Action

> Ver `00_marco_transversal.md` para el marco obligatorio compartido.

## Señales
Detectar movimiento de línea, movimiento de cuota, Reverse Line Movement,
porcentaje de tickets, porcentaje de dinero cuando esté disponible,
diferencias entre books, steam moves y posibles posiciones sharp.

## Método
Comparar apertura, precio actual, dirección del movimiento, timing,
liquidez y noticias. Un movimiento contra el porcentaje de tickets puede
ser informativo, pero no prueba dinero profesional. Confirmar que se trate
del mismo mercado y que no haya cambio de pitcher, lineup o reglas del
book.

## Regla
El movimiento de línea nunca decide por sí solo. Debe analizarse junto con
proyección, precio, mercado y contexto. Registrar si el movimiento mejora
o empeora el precio antes de recomendar.
